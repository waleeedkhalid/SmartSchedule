⚠️  ERROR FIX: "Could not find table 'public.course'"
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

This means your database tables haven't been created yet.
Follow these steps:

STEP 1: Create Supabase Project
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
1. Go to https://supabase.com
2. Click "New Project"
3. Fill in project details and click "Create"
4. Wait ~2 minutes for setup to complete

STEP 2: Get Your Credentials
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
1. In your Supabase project, go to:
   Project Settings → API
2. Copy these two values:
   - Project URL
   - anon/public key

STEP 3: Configure Environment
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
1. Copy .env.local.example to .env.local:
   
   cp .env.local.example .env.local

2. Edit .env.local and paste your credentials:

   NEXT_PUBLIC_SUPABASE_URL=https://xxxxx.supabase.co
   NEXT_PUBLIC_SUPABASE_ANON_KEY=eyJhbGci...

STEP 4: Run Database Migrations ⭐ IMPORTANT!
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
1. Go to your Supabase dashboard
2. Click "SQL Editor" in the left sidebar
3. Click "New Query"
4. Copy and paste the ENTIRE content of these files IN ORDER:

   📄 File 1: supabase/migrations/20241027000001_initial_schema.sql
   ↓ Click "Run" after pasting
   
   📄 File 2: supabase/migrations/20241027000002_rls_policies.sql
   ↓ Click "Run" after pasting
   
   📄 File 3: supabase/migrations/20241027000003_helper_functions.sql
   ↓ Click "Run" after pasting

STEP 5: Create Your First User
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
1. In Supabase dashboard: Authentication → Users
2. Click "Add User"
3. Enter email and password
4. Click "Create User"
5. Copy the user ID

STEP 6: Add User Role
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
1. Go to SQL Editor again
2. Run this query (replace YOUR_USER_ID and YOUR_EMAIL):

INSERT INTO user_roles (user_id, role, name, email)
VALUES (
  'YOUR_USER_ID',
  'scheduling',
  'Your Name',
  'YOUR_EMAIL'
);

STEP 7: Start the App!
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
pnpm dev

Visit: http://localhost:3000

STEP 8: Verify Setup
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
After logging in, go to:
  Dashboard → Setup Check

This will tell you if everything is configured correctly!
