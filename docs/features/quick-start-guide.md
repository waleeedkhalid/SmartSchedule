## Faculty Quick Start

### Setting Your Availability

1. **Navigate to Availability Page**
   - Go to `/faculty/availability`
   - Or click "Availability" from faculty dashboard

2. **Set Your Preferences**
   - Select days you're available
   - Set preferred time slots
   - Mark any time off periods
   - Save changes

3. **View Your Schedule**
   - Go to `/faculty/schedule`
   - See your assigned courses
   - Check for conflicts
   - Download as PDF/CSV

### Submitting Feedback

1. **Navigate to Feedback Page**
   - Go to `/faculty/feedback`

2. **Submit Feedback**
   - Select the schedule
   - Rate satisfaction
   - Add comments
   - Submit

### Common Tasks

| Task | Location | Time Required |
|------|----------|---------------|
| Update availability | `/faculty/availability` | 2-5 minutes |
| View schedule | `/faculty/schedule` | < 1 minute |
| Submit feedback | `/faculty/feedback` | 2-3 minutes |
| View courses | `/faculty/courses` | < 1 minute |

## Scheduler Committee Quick Start

### Generating a Schedule

1. **Navigate to Dashboard**
   - Go to `/committee/scheduler/dashboard`

2. **Select Active Term**
   - Ensure correct academic term is selected
   - Verify term dates are correct

3. **Check Prerequisites**
   - ✅ Courses are loaded
   - ✅ Rooms are configured
   - ✅ Faculty availability collected
   - ✅ Student counts reviewed

4. **Generate Schedule**
   - Go to Schedule Generation page
   - Configure constraints
   - Click "Generate Schedule"
   - Review generated schedule

5. **Resolve Conflicts**
   - Check conflict report
   - Use automatic suggestions
   - Manually resolve remaining conflicts
   - Verify resolution

6. **Publish Schedule**
   - Review final schedule
   - Get approval (if required)
   - Publish to students/faculty
   - Send notifications

### Managing Courses

1. **View Course List**
   - Go to `/committee/scheduler/courses` or `/committee/courses`
   - Filter by level, type, or status

2. **Add New Course**
   - Click "Add Course"
   - Fill in details (code, name, credits, type)
   - Set prerequisites (if any)
   - Save

3. **Manage Sections**
   - Select course
   - Add sections
   - Set capacity
   - Assign rooms (if known)

### Monitoring Student Counts

1. **Navigate to Student Counts**
   - Go to `/committee/scheduler/student-counts`

2. **View by Different Criteria**
   - **By Course**: See enrollment per course
   - **By Level**: See distribution by student level
   - **By Type**: Compare Required vs Elective

3. **Analyze Capacity**
   - Check utilization percentages
   - Identify over/under-capacity courses
   - Export data for planning

4. **Export Data**
   - Click "Export CSV"
   - Open in spreadsheet software
   - Perform additional analysis

### Configuring Rules

1. **Navigate to Rules**
   - Go to `/committee/scheduler/rules`

2. **Create New Rule**
   - Click "Add Rule"
   - Select rule type
   - Set parameters
   - Set priority
   - Save

3. **Test Rule**
   - Use "Test Rule" feature
   - Verify rule behavior
   - Adjust as needed

### Scheduling Exams

1. **Navigate to Exam Scheduling**
   - Go to `/committee/scheduler/exams`

2. **Configure Exam Period**
   - Set start/end dates
   - Configure time slots
   - Set default duration

3. **Generate Exam Schedule**
   - Click "Generate"
   - Review conflicts
   - Resolve issues
   - Publish

### Common Tasks

| Task | Location | Time Required |
|------|----------|---------------|
| Generate schedule | Scheduler Dashboard | 5-15 minutes |
| Resolve conflicts | Conflict Resolution | 10-30 minutes |
| Review student counts | Student Counts | 5-10 minutes |
| Add course | Course Management | 2-3 minutes |
| Configure rules | Rules Configuration | 5-10 minutes |

## Registrar Quick Start

### Managing Academic Timeline

1. **Navigate to Timeline**
   - Go to `/committee/registrar/timeline`

2. **Create Academic Term**
   - Click "Add Term"
   - Set start/end dates
   - Define key dates
   - Save

3. **Add Timeline Events**
   - Select term
   - Click "Add Event"
   - Set event type (e.g., "Registration", "Drop Deadline")
   - Set date
   - Enable/disable related features
   - Save

   - Select term

## Troubleshooting

### Common Issues

#### "Access Denied" or "Unauthorized"

**Problem:** You don't have permission to access a page.

**Solutions:**
1. Verify you're logged in
2. Check your assigned role
3. Contact administrator if role is incorrect

#### "Schedule Not Loading"

**Problem:** Dashboard or schedule page shows loading indefinitely.

**Solutions:**
1. Refresh the page (F5)
2. Clear browser cache
3. Check internet connection
4. Try different browser
5. Contact support if persists

#### "Cannot Submit Preferences"

**Problem:** Elective preference submission fails.

**Solutions:**
1. Check if submission period is open (see timeline)
2. Ensure you've selected required number of preferences
3. Verify all required fields are filled
4. Try again after a few minutes

#### "Faculty Availability Not Saving"

**Problem:** Changes to availability don't persist.

**Solutions:**
1. Ensure you click "Save" button
2. Check for error messages
3. Verify date ranges don't overlap
4. Try logging out and back in

#### "Slow Performance"

**Problem:** Pages load slowly or timeout.

**Solutions:**
1. **Good news:** Major performance fix applied October 25, 2025
2. Refresh page to ensure latest version
3. Clear browser cache
4. Try during off-peak hours
5. Contact support if issue persists

## Best Practices

### For Faculty

1. **Update availability early** - Do this at the start of each term
2. **Be specific** - Mark exact unavailable times
3. **Review regularly** - Check your schedule weekly
4. **Provide feedback** - Help improve the system

### For Committee Members

1. **Start early** - Begin schedule planning 4-6 weeks before term
2. **Collect data first** - Get faculty availability and student counts
3. **Review thoroughly** - Check for conflicts before publishing
4. **Communicate clearly** - Notify affected parties of changes
5. **Document decisions** - Keep records of manual overrides

### For Registrar

1. **Set timeline first** - Configure academic term before other activities
2. **Enable features gradually** - Open registration, then electives, etc.
3. **Monitor deadlines** - Set reminders for key dates
4. **Communicate early** - Announce deadlines well in advance

### For Students

1. **Submit early** - Don't wait until deadline for preferences
2. **Be flexible** - Rank multiple electives to increase chances
3. **Check regularly** - Monitor for schedule updates
4. **Provide feedback** - Help improve future schedules
